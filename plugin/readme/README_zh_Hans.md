# 本地修图工作室

本插件在承载它的 Dify 插件进程内，以 Pillow、NumPy 和 OpenCV 执行固定 JSON 修图方案。它不调用外部生图服务、不下载模型权重、不执行模型生成的 Python 或 Shell。插件本身不调用大模型；理解自然语言、识图、规划和复核需要由外围 Chatflow 及已配置模型完成。

源码：https://github.com/liaoliaochenfeng2/dify-local-retouch  
反馈：https://github.com/liaoliaochenfeng2/dify-local-retouch/issues

## 安装条件

需要 Dify 1.16.1 或更高版本、Python 3.12 插件运行环境，并能从管理员允许的软件包源或离线镜像安装固定版本依赖。插件申请 1 GiB 进程内存和 1 GiB SDK 存储；实际运行时限、并发和配额由平台控制。插件不要求 API Key、外部图像服务、单独渲染服务器或 GPU。

公开上架后可从市场安装；允许本地安装的部署也可使用 `.difypkg`。公开源码仓库和发布者 `liaoliaochenfeng2` 已确认，当前版本为发布候选。67 项本地核心测试和 SDK 检查已通过，实际 Dify 安装验证及公开联系邮箱仍待补齐；尚未向 Marketplace 提交 PR，也未获市场审核通过。安装工具不会自动创建完整的对话修图应用；仍需配置 Chatflow。不要为了安装绕过所在平台的验证策略。

## 两个工具

- `prepare`：整理原图、风格参考图、选区和替换背景，读取会话配方与明确保存的偏好，输出原始素材、识图缩略图和相关风格卡。
- `retouch`：执行经过校验的完整配方，从原图重算，生成全尺寸 PNG 或 A/B 两个小样，返回处理报告并保存续改状态。

`user_id`、`conversation_id` 和 `query` 必须分别直接绑定 `sys.user_id`、`sys.conversation_id` 和 `sys.query`，不能让模型编造。应用身份来自 SDK 会话；缺少可靠应用身份时停用跨会话偏好。

文件输入必须只绑定可信的 Dify 托管上传。SDK 可能通过 HTTP 获取这些文件的 URL；承载平台必须在下载前校验文件地址、限制上传大小及出站网络访问。本插件的 20 MiB 字节校验发生在 SDK 取回数据之后，不能独立作为 SSRF 防护或下载带宽限制。

上传图片用 `asset_roles` 按顺序明确为 `source/reference/mask/background`，每种角色最多一张，每轮最多四张。参考图仅用于色彩统计匹配，不能自动当成替换背景。将 prepare 返回的原始素材接入 retouch 对应输入，`source_sha256` 和 `context_revision` 直接绑定 prepare 的输出。缩略图只用于观察，不得替代原图。

## 能力与边界

支持整体和局部调色、轻度双边平滑、小区域传统修补、背景合成及小幅液化，以及曝光/高光/阴影/黑白场、RGB 曲线、分色 HSL、八种基础风格和参考图色彩统计匹配。参考匹配不移植人物、构图或场景，不复刻光线结构。

八种基础风格为清透自然、暖柔光感、冷调杂志、哑光胶片、暖调复古、夜景氛围、旅行鲜明、中性人像。英文指导与中文口语例子只是规划参考，不保证模型理解所有抽象描述。资源内 36 条中文语义案例是人工编写的测试期望，尚未完成所配置模型上的实际评估。

每个配方最多 10 步，风格及参考匹配各最多一次。小区域修补单步不超过全图 8%、累计不超过 12%；不能保证复杂大面积去人。GrabCut 需要合理的前景范围，发丝和复杂背景可能需要准确蒙版。背景替换支持纯色或上传背景，不支持凭文字生成新场景。无换衣、改变姿态、补出复杂遮挡内容、扩图或自动上网能力。

肤色保护是颜色启发式，只减弱部分调整，不是精准人像分割或保证肤色完全不变。磨皮与液化不是自动人体重建；曝光和曲线不能恢复已剪切的细节。交付前需复核成品和蒙版。

## 图片与输出

接受静态 JPEG、PNG、WebP；单张最多 20 MiB，每边 16 至 6000 像素，总计不超过 1260 万像素。应用 EXIF 方向并按有效 ICC 转为 sRGB，拒绝高位深或浮点输入。成品保持转正后的原图尺寸，不自动缩小以绕过限制，输出 8 位 PNG，不带原图 EXIF。

蒙版须与转正后的原图同尺寸。普通局部处理白色表示修改、黑色表示保留；换背景时白色表示保留主体、黑色表示替换背景。`selection_mask.png` 是最后一个相关操作的选区，具体含义见报告。

最终结果包含 `xiaorun_retouched.png`、`review_preview.jpg`、`recipe.json`，必要时含 `selection_mask.png`。双小样包含 `candidate_A.jpg`、`candidate_B.jpg`、`review_preview.jpg` 和 `recipe.json`；候选图为缩略预览，选定后才生成全尺寸成品。出错不返回部分成品。

## 多轮与偏好

每次按完整配方从原图重算，避免重复压缩和叠加滤镜。新原图会清空本会话旧素材和配方，保留明确保存的偏好。裸选 A/B 可直接使用已保存配方；“选 B，再淡一点”必须以 B 为基准处理额外要求，不能忽略修饰语。

只有原话明确表达“记住、以后、今后、默认、我的偏好”等长期意图，且不是拒绝保存时，才允许写入长期偏好。本版长期偏好保存检测器只识别这些中文线索；普通“太红了、淡一点”只影响当前修改。最多保存八条、合计 1600 字。

会话有效期 24 小时，固定 64 个槽，单会话素材及元信息最多 12 MiB；偏好有效期 90 天，固定 4096 个槽，每条记录最多 4 KiB。均可能提前被淘汰，不是永久相册。超出缓存大小的大图仍可当轮处理，但可能无法续改。出现缓存警告后，下一轮需重新上传原图及所需素材。

使用 `reset` 清空会话插件缓存，`reset_preferences` 清空偏好。有效期是读取时检查的逻辑过期，不代表到期立即物理擦除。插件清空不会删除平台上传、聊天记录、成品、日志或备份，相关记录依照承载平台策略管理。
