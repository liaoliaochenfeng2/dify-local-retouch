# 数据处理说明

插件在承载它的 Dify 插件环境内处理上传照片、参考图、选区、背景、当前请求、修图配方、报告、用户/会话/应用标识和明确保存的偏好。照片可能包含个人信息。插件不做人脸身份识别、不建立生物识别身份模板、不把照片用于训练，不接入分析或遥测服务。

原图缓存和 prepare 返回的原始素材保留上传字节，可能包含原始 EXIF 和 GPS 信息。最终编辑图片省略原图 EXIF；预览和报告仍可能包含照片或用户文字，应按用户内容保护。

图像处理由 Pillow、NumPy、OpenCV 在插件进程完成，不调用外部图像 API、不提供任意网址抓取功能、不下载模型权重、不执行任意 Python/Shell。SDK 会读取平台文件并访问插件存储，也可能通过 HTTP 获取平台文件的 URL。因此工具输入只能绑定可信的 Dify 托管上传；承载平台负责校验文件地址、限制出站访问，并在下载前施加上传大小和带宽限制。本插件的字节大小校验发生在 SDK 取回数据后，不能独立充当 SSRF 防护边界。安装依赖可能访问管理员配置的软件包源或镜像。外围应用的语言、视觉模型及其数据去向由平台另行配置，插件本身不调用大模型。

为支持续改，原图、参考图、蒙版、背景和配方元信息可进入 Dify SDK 存储。会话按应用、用户、会话隔离，偏好按应用与用户隔离。所属者键使用哈希标识，但哈希不等于匿名化。可用 SDK 身份会与输入身份核对；无可信应用身份不启用跨会话偏好。

会话缓存 24 小时逻辑有效期，64 个槽，单条不超过 12 MiB。偏好 90 天逻辑有效期，4096 个槽，单条不超过 4 KiB；偏好文字不超过八条、1600 字，须有明确支持的中文长期保存指令。缓存可能提前被淘汰。过期在读取时执行，底层记录在访问、覆盖或明确清空时回收，并非到期立即擦除。

`reset` 清空当前会话插件缓存；`reset_preferences` 清空当前应用下该用户的偏好。清空失败会明确报错。插件清空不删除平台原始上传、聊天记录、输出、日志或备份，应向平台运营方咨询这些记录的保留和删除策略。

插件会向平台返回状态、校验错误和处理报告；平台可能按自身策略记录工具输入输出。报告包含用户给定的标签与说明，不应在请求、文件名、偏好中填写密钥或敏感凭证。
